# SuperNova

## Explore cosmos and learn something new about it

SuperNova - a project designed to increase interest in space and provide tools for engaging learning in this field.

# Web applicatioon with interactive Solar System

A fullstack interactive 3D solar system built with React, TypeScript,
Node.js, Express, PostgreSQL and Three.js.

Explore planets, control the simulation, move around the scene,
and learn more about each planet.

## Features

- User registration and authentication
- JWT-based authentication
- Interactive 3D solar system
- Individual pages for each planet
- Pause and resume simulation
- Camera reset controls
- Fullscreen 3D mode
- Interactive camera controls
- Responsive interface
- Client and server-side validation
- Dockerized development environment
